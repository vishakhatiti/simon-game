🎮 Simon Game
A fun and interactive **memory-based game** built using HTML, CSS, and JavaScript.

🚀 Live Demo
https://simon-game-vishakhatiti.netlify.app/

🧠 How to Play
* Press any key to start the game
* Watch the sequence of colors carefully
* Repeat the same sequence by clicking the buttons
* Each level adds a new color to the pattern
* Game ends if you click the wrong color

🛠️ Tech Stack
* HTML
* CSS
* JavaScript
* jQuery

✨ Features
* Dynamic color sequence generation
* Sound effects for each button
* Level progression system
* Game over alert with restart option

📁 Project Setup
1. Download or clone the repository
2. Open `index.html` in your browser
